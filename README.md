# 90 Days of MERN Stack Web Development 🚀

Welcome to my **90-Day MERN Stack Web Development** challenge repository! This repo tracks my daily journey, projects, code snippets, and progress as I master full-stack web development using MongoDB, Express.js, React, and Node.js.

---

## 📅 Roadmap Overview

- **Days 1–15:** HTML5, CSS3 & Responsive Web Design
- **Days 16–30:** Modern JavaScript (ES6+), DOM Manipulation & Asynchronous JS
- **Days 31–45:** React.js (Components, Hooks, State Management & Routing)
- **Days 46–60:** Node.js & Express.js (REST APIs, Middleware, Authentication)
- **Days 61–75:** MongoDB & Mongoose (Database Design, CRUD, Aggregations)
- **Days 76–90:** Full-Stack MERN Projects, Deployment & Optimization

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Tools & Platforms:** Git, GitHub, Postman, VS Code
